# Feirão do Livro — React Native

Aplicativo baseado no desenho da cliente da atividade **Do Papel ao Expo**.

## Funcionalidades

- Início → Ver acervo
- Início → Como participar
- Como participar → Voltar
- Acervo → tocar em qualquer livro
- Livro → Detalhe do Livro
- Detalhe → Troca (simulada)
- Detalhe → Voltar para Acervo

Os livros são fictícios por enquanto, conforme o pedido da atividade.

## Rodar

```bash
npm install
npx expo start
```

Depois, use o QR Code no Expo Go ou pressione `w` para abrir no navegador.
